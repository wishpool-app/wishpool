# 🪙 Wishing Pool 许愿池

**https://wishpool.xin** — Write your wish, hear from your future self.

写下愿望，投一枚金币，「未来的你」会用声音给你回信。

## ✨ Features 功能
- 🪙 许愿投币：星空许愿池 + 金币涟漪动画
- 💌 未来的你：第一人称语音来信（中文/English）
- ✅ 每日肯定语：基于你的愿望每日生成，可自定义
- 📚 7 天显化课：丰盛 / 爱 / 自信 / 感恩 四门课程
- 🔥 连续打卡、收藏体系、每日提醒
- 💾 数据导出/导入备份（JSON）
- 🌐 中英双语，PWA 可安装到主屏幕
- 📄 [200 条显化语大全](https://wishpool.xin/manifestation-quotes.html) · [许愿指南](https://wishpool.xin/how-to-wish.html) · [今日显化语](https://wishpool.xin/daily-affirmation.html)

## 🛠 Tech
纯前端单页应用（零依赖、零服务器成本），Web Speech API 语音朗读，WebAudio 音效，localStorage 本地存储。

部署：GitHub Pages · 域名 wishpool.xin
